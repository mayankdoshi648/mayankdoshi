The 15 workflows

Capture. Process. Reuse.

Start with an inbox and one nightly pass. Add the rest only when those feel automatic.

01 ~30 min/day

Daily Capture Inbox

One inbox note for the day. Everything lands here first — ideas, links, tasks, voice dumps. No organizing in the moment.

How it works

  1. Open today’s daily note.
  2. Under an Inbox section, dump thoughts, URLs, tasks, and half-formed ideas.
  3. Do not file, tag, or structure yet. Speed matters more than structure.
02 ~20 min/day

Evening Processing Loop

A 10-minute nightly pass that files inbox items into the right notes, tasks, or archive. Stops the vault from rotting.

How it works

  1. Review the day’s inbox.
  2. Develop it into a proper note in 01 - Notes.
  3. Attach it to a project in 02 - Projects.
  4. Move it to 03 - Resources, extract tasks, or delete passing thoughts.
03 Hours over time

Atomic Note Split

One idea = one note. Long dumps get split so they can be linked and reused later.

How it works

  1. When processing inbox items, if a note contains multiple ideas, split them.
  2. Create separate notes for each concept.
  3. Link them together with [[ ]] syntax.
04 ~1 hr/week

Meeting → Action Pipeline

Raw notes go in. A template extracts decisions, owners, and next actions. Meeting notes stop being a graveyard.

How it works

  • Attendees, Agenda, Key points
  • Decisions made
  • Action items with owners and due dates
  • Follow-ups — then extract actions into your task query and link the meeting to projects
05 ~3 hrs/week

Task Query Instead of a To-Do App

Tasks live in notes. A Dataview/Tasks query answers “what should I do next?” without a separate PM tool.

How it works

  1. Use the Tasks plugin or Dataview for queries like not-done tasks due before tomorrow, sorted by priority.
  2. Create views for today’s tasks, overdue, by project, and by context.
06 ~45 min/week

Weekly CEO Dashboard

One note that pulls open projects, overdue tasks, and unfinished ideas. Weekly review takes minutes, not an hour.

How it works

  1. Link all seven daily notes from that week.
  2. Query open projects, overdue tasks, and unfinished drafts with Dataview.
  3. Spend 20–30 minutes every Sunday reviewing and planning.
07 ~2 hrs/week

Research Clip → Permanent Note

Web clips and highlights get a short rewrite in your own words, then get linked. Reading time becomes reusable knowledge.

How it works

  1. Clip articles to an inbox folder.
  2. Rewrite key insights in your own words.
  3. Create permanent notes for each major concept and link to related notes and sources.
08 ~2 hrs/week

Content Idea Vault

Every idea is captured with a hook, angle, and source. When it’s time to write, you pick from a list instead of starting blank.

How it works

  • Template fields: core idea, hook options, audience, formats, status
  • Store ideas in a Content Ideas folder
  • Query by status when planning content
09 ~3 hrs/week

Article / Thread Assembly Workflow

Outline note + linked research notes + draft note. Writing becomes assembling, not hunting for material.

How it works

  1. Create an outline note with sections.
  2. Link to relevant research and concept notes.
  3. Write the draft in a separate note and use the outline to stay on track.
10 ~1 hr/week

Template-First Capture

New notes start from templates (daily, meeting, project, concept). Structure is automatic, so you never rebuild the same format.

How it works

  1. Use the Templates plugin.
  2. Create templates for daily, meeting, project, concept, and content ideas.
  3. Set hotkeys or use the command palette to insert templates quickly.
11 ~2 hrs/week

Project Home Note

Each project has one hub: goal, status, links, next action. No more jumping between five apps to remember where a project stands.

How it works

  • Goal, current status, next actions
  • Related notes and links, blockers or risks
  • One note per project in 02 - Projects, updated weekly
12 ~2 hrs/week

AI Query Over the Vault

Ask Claude/Cursor against your notes: “What did I already decide on X?” Retrieval replaces rereading.

How it works

  1. Point an AI tool at your vault.
  2. Ask what you decided, what questions remain, or for a thinking summary on a concept.
  3. Get synthesized answers without manual searching.
13 ~1 hr/week

Link-as-You-Go

New notes get 2–3 links immediately. The graph stays useful because connections are created at capture time, not later.

How it works

  1. Ask what existing notes, projects, and concepts this relates to.
  2. Add 2–3 [[ ]] links before closing the note.
14 ~1 hr/week

Weekly Cleanup Sweep

Archive stale notes, merge duplicates, fix empty stubs. Fifteen minutes a week prevents a bloated, unsearchable vault.

How it works

  • Archive unused notes, merge duplicates, delete empty stubs
  • Fix broken links
  • Use Unlinked references to find orphaned notes
15 ~2 hrs/month

Recurring Review Notes

Monthly / quarterly notes that pull wins, open loops, and themes. Planning becomes review, not reconstruction from memory.

How it works

  1. Create monthly and quarterly review templates.
  2. Use Dataview for completed work, key decisions, themes, and open questions.
  3. Adjust direction based on actual progress.

Pitfalls

What most people get wrong

Overbuilding plugins before a daily habit exists

Start with daily notes and one processing loop. Add plugins later.

Capturing everything and processing nothing

An inbox that grows indefinitely provides no value. Process to zero regularly.

Using Obsidian as storage instead of a working system

Notes should be connected, queried, and reused — not just stored.

Adding AI without a clean note structure first

AI amplifies what you have. Messy notes make messy outputs faster.

This week

How to start this week

Do not try to implement all 15 workflows at once.

Week 1

Create an inbox + daily note. Add one processing loop at night.

Week 2

Pick 3 workflows that match your biggest time leak — for example Daily Capture Inbox, Evening Processing Loop, and Task Query. Ignore the rest until those three feel automatic.

Week 3–4

Add 2–3 more workflows. Refine templates and queries based on actual use.

Obsidian saves serious time only when it becomes a set of workflows, not a pile of notes.

These 15 systems quietly remove the work of remembering, searching, and restarting. Start small, keep them boring, and let the hours compound.
