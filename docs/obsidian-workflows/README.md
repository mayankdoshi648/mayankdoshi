# Daily Loop — Obsidian productivity workflows

Ready-to-paste templates and folder layout for the **15 Daily Loop workflows**. Pair with the guide at [`/obsidian-workflows.html`](../frontend/obsidian-workflows.html) when the dashboard server is running.

## Folder layout

Create these folders in your vault (DarvaX watchlist exports can live under Resources or a sibling `03-Watchlists/` folder):

```text
00-Inbox/
01-Daily/
02-Projects/
03-Concepts/
04-Resources/
05-Archive/
06-Content/
99-Templates/
```

Copy everything from `templates/` into `99-Templates/`.

## Processing checklist (Workflow 2)

For each inbox item:

1. Develop → new note in `03-Concepts/` or `04-Resources/`
2. Attach → link from a `02-Projects/` home note
3. Task → `- [ ]` with due date / priority in a project or daily note
4. Delete → passing thought
5. Always add 2–3 `[[wikilinks]]` before you close a new note (Workflow 13)

## AI query prompts (Workflow 12)

Use only after notes are linked and processed:

- What did I already decide about [[topic]]?
- What are my open questions on [[subject]]?
- Summarize my thinking on [[concept]] with sources.
